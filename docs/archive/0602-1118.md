# 作業指示: Density Heatmap Overlay P0

## 目的
既存の density grid 診断結果を使い、点群ビュー上に表示点ベースの密度ヒートマップを重ねる。

## 重要前提
- 新しい外部依存は追加しない。
- 単一HTMLを維持する。
- サーバー処理は追加しない。
- LAS/LAZ読込処理は触らない。

## 対象ファイル
- PointCloudWorkbench.html
- scripts/pointcloud-workbench.test.js
- README.md
- docs/README.ja.md
- docs/README.en.md
- PointCloudWorkbench_運用手順書.md
- PointCloudWorkbench_実装リファレンス.md

## 実装内容
1. 既存の densityGrid を取得する
2. densityGrid.cells を canvas に描画する
3. canvas を THREE.CanvasTexture にする
4. XY bounds に合わせた PlaneGeometry を作る
5. 点群の下または少し上に半透明 overlay として表示する
6. ON/OFF、opacity、legend をUIに追加する

## UI

- 密度ヒートマップ ON/OFF
- 透明度
- 凡例

## 完了条件
