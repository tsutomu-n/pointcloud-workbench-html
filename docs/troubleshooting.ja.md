# トラブルシューティング

timestamp="2026-11-20(金)_23:40 JST"

## アプリが起動しない

確認:

- ChromeまたはEdge最新版か
- ネットワーク接続があるか
- JS/WASMの取得がブロックされていないか
- 社内プロキシやセキュリティソフトでCDNが止められていないか

## LAS/LAZが読み込めない

確認:

- 拡張子が `.las` または `.laz` か
- ファイルサイズ上限を超えていないか
- LASは3GB超で拒否される
- LAZは2GB超で拒否される
- まずLOW品質で試す

Issueで報告する場合:

- 読み込みに失敗した場合は、どの操作で止まったかと画面に出たエラーメッセージを記録する
- 読み込み後の問題を報告する場合は、「統計情報」の末尾にある「診断情報をコピー」からJSONを添える
- 診断情報は手動コピーのみで、自動送信されない
- 診断情報にはCRS、取得品質、地表候補などの要約が含まれる
- LAS/LAZファイル本体、ローカルファイル名、元LAS座標配列は診断情報に含めない

現場状況や操作状態も共有する場合:

- 統計パネルの「作業メモコピー」を押す
- 表示状態、断面、計測、異常候補、取得品質、地表候補の要約JSONを貼り付ける
- 作業メモも手動コピーのみで、自動送信されない

## 画面が重い

対応:

1. LOW品質で読み込む。
2. 分類表示ではなく標高表示にする。
3. スライスを使用中なら、「スライス表示」を開いて「スライスを一時解除」を押す。設定欄を閉じている間も切断は適用される。
4. 他のブラウザータブを閉じる。
5. Chrome/Edgeを再起動する。

## 外部地図リンクが使えない

確認:

- 点群にCRS情報があるか
- 対応する JGD2011 平面直角座標系の EPSG 候補が1つに絞れているか
- bounds 中心が取得できているか
- `proj4js` の取得がブロックされていないか
- Google Maps / 地理院地図への外部リンク遷移が社内プロキシやブラウザー設定でブロックされていないか

## スクリーンショットに地図が入らない

現行実装はアプリ内に地図タイルを表示しません。
点群のみのスクリーンショットを使ってください。

## 地表候補の confidence が低い

確認:

- ground分類点が少ない、または分類されていない可能性がある
- `p05推定` は分類が薄い場合の下位パーセンタイル推定であり、成果品DTMではない
- 勾配、土量、設計面比較の根拠に使わない
