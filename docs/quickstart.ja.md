## 目的

PointCloudWorkbenchを使って、ブラウザー上でLAS/LAZ点群を確認します。

## 必要なもの

- 最新の Google Chrome または Microsoft Edge
- ネットワーク接続
- 可能ならメモリに余裕のあるPC

Safari、Firefox、古いブラウザーは対応対象外です。

## ファイルなしで試す

1. [河川と橋のサンプルを開く](https://tsutomu-n.github.io/pointcloud-workbench-html/PointCloudWorkbench.html?lang=ja&demo=river)と、合成点群が読み込まれます。
2. 「橋を横切る断面を見る」で断面を開き、厚さを変えて表示点の数を比較します。
3. 「橋を測る」を押して A・B を選びます。水平距離 60 m が履歴に追加されます。「CSVコピー」で結果を控えられます。
4. 「密度を見る」で右岸の表示点が 0 の区画を確認します。スマホではモデル右上の「ツール」で操作欄を開けます。各機能の「？」からヘルプを表示できます。

## 手元のLAS・LAZを開く

1. [アプリを開きます](https://tsutomu-n.github.io/pointcloud-workbench-html/PointCloudWorkbench.html?lang=ja)。サンプルを開いている場合は「自分のファイルを開く」で戻れます。
2. `.las` または `.laz` ファイルを選び、「品質設定へ」を押します。
3. Preflight画面で以下を確認します。
   - ファイルサイズ
   - 元点数
   - 推定表示点数
   - 表示率
   - メモリリスク
   - 推奨品質
4. `LOW / MEDIUM / HIGH / MAX` から品質を選びます。
5. 読み込みを開始します。
6. 読み込み後、3D/2D、スライス、分類、統計を確認します。
7. 統計パネルで以下を確認します。
   - CRS 診断
   - 取得品質
   - 地表候補
   - 地表方式
8. 状況共有が必要な場合は「診断情報をコピー」または「作業メモコピー」を使います。

## 注意

このアプリは点群ファイルをサーバーへアップロードしません。
選択したLAS/LAZファイルはブラウザー内で処理されます。

ただし、アプリ本体、LAZデコーダ、描画コード、CDN配信ライブラリの取得にはネットワーク接続を使います。
現行実装では地図タイルをアプリ内に埋め込まず、対応 CRS の bounds 中心から Google Maps / 地理院地図への外部リンクを作ります。

地表候補は表示点ベースの参考診断です。
測量成果DTM、設計面、切盛根拠、納品用地形モデルではありません。
